💥 Tiga Mode Kegagalan Katastropik Perangkat Lunak

  • Mode 1: Interrupt Storm & CPU Exhaustion / Denial-of-Sleep
    Injeksi runt glitches berulang (<400 µs) memicu ribuan External Interrupts (EXTI ISR) per detik. Beban CPU melonjak hingga 100%, thread aplikasi lumpuh (CPU starvation), dan daya MCU naik dari level tidur mikroampere ke 4.0–16.5 mW, menguras baterai utilitas dalam hitungan hari.
  • Mode 2: Buffer Overflow & Memory Corruption (Heap/Stack Bleed)
    Injeksi paket termutilasi (<192 bit) atau frame kelebihan muatan (>192 bit) membanjiri ring-buffer DMA/UART sebelum rutin CRC software sempat dieksekusi. Memicu out-of-bounds write, penimpaan pointer eksekusi, dan kegagalan peripheral permanen.
  • Mode 3: Asynchronous Desynchronization & Silent Data Corruption
    Injeksi jitter pada rentang terlarang (11–15 siklus) mengacaukan pemulihan clock (bit-slip). Software membaca angka meteran listrik/air atau status kunci brankas sekuriti yang korup tanpa memicu exception.

Formulasi Matematika Trust Boundary

Ortogonalitas Ruang Waktu Pulsa Manchester Diskrit & Verifikasi Tata Bahasa Protokol

📐 Persamaan Utama Kepercayaan Silikon

Keabsahan paket ditegakkan secara mutlak melalui konjungsi logika biner ganda antara domain waktu fisik gelombang dan sintaksis tata bahasa protokol:

$$\mathbf{\boxed{V_{\text{trusted}} = V_{\text{physical}} \land V_{\text{protocol}}}}$$

Prinsip Fail-Closed Mutlak: Jika salah satu kondisi bernilai 0, maka $V_{\text{trusted}} = 0$ secara permanen, memutus transmisi ke host MCU.

⏱️ Kepatuhan Domain Waktu Fisik ($V_{\text{physical}}$)

Pada $F_{\text{clk}} = 20.00\,\text{kHz}$ ($T_{\text{clk}} = 50.0\,\mu\text{s}$), durasi antar-transisi tepi $T_k$ dikuantisasi ke pencacah register diskrit $N$:

  • Half-Bit Window ($N_{\text{HB}}$): $N \in [8, 10]\,\text{siklus} \ (400 - 500\,\mu\text{s})$ [Nominal: $N=9$].
  • Full-Bit Window ($N_{\text{BIT}}$): $N \in [16, 20]\,\text{siklus} \ (800 - 1000\,\mu\text{s})$ [Nominal: $N=18$].
  • Zona Glitch Terlarang: $N \le 7\,\text{siklus} \ (T_k \le 350\,\mu\text{s}) \implies$ Sinyal Fault Seketika.
  • Zona Desync Terlarang: $N \in [11, 15]\,\text{siklus} \ (550 - 750\,\mu\text{s}) \implies$ Sinyal Fault Seketika.
  • Zona Timeout Jeda: $N \ge 21\,\text{siklus} \ (T_k \ge 1050\,\mu\text{s}) \implies$ Status Jeda Pending.

🔇 Eliminasi Squelch & Ketidaksamaan Ambang Batas

Ambang deteksi akhir paket ($N_{\text{EOF}} = 64$ siklus $= 3.20\,\text{ms}$) memisahkan desis derau acak RF (1–4 siklus) dari jeda antar-paket ($G_{\text{IFG,min}} = 6547$ siklus $= 327.35\,\text{ms}$):

$$\mathbf{N_{\text{TIMEOUT}} < N_{\text{EOF}} < G_{\text{IFG,min}} \iff 21 < 64 < 6547}$$

Rasio Margin Temporal Keselamatan = 102.3× (20.1 dB)

Margin $102.3\times$ ini menjamin Sentinel kembali bersih ke status IDLE jauh sebelum frame berikutnya tiba, tanpa risiko false alarm pada derau RF lingkungan.

📜 Formulasi Tata Bahasa Protokol ($V_{\text{protocol}}$)

Struktur frame 192-bit divalidasi pada saat sampel clock pertama:

[Preamble: 32b 0xAAAAAAAA] || [Type1: 16b 0xD391] || [Type2: 16b 0xD391] || [Constant: 32b 0x0DFFFFFE] || [Payload: 72b Telemetri] || [Trailer: 24b]

Jika ada deviasi bit statis atau panjang $\ne 192$ bit $\implies V_{\text{protocol}} = 0$ seketika.

"The Silicon Bouncer" — Paradigma Pertahanan Berlapis Tiga di Perbatasan Fisik Gerbang Silikon

🛡️ Layer 1: Temporal Sentinel

Modul: ares_timing_sentinel.v
Fungsi: Mengawal integritas fisik pulsa radio secara real-time pada resolusi 50 µs (clock 20 kHz).

  • Pencacah interval kontinu 8-bit (0..255).
  • Komparator jendela [8,10] & [16,20] siklus.
  • FSM 4-status pelacak konteks (IDLE, ARMED, ACTIVE, LONG_GAP).
  • Anti-squelch filter yang menahan derau awal tanpa alarm palsu.

📜 Layer 2: Frame Syntax Monitor

Modul: ares_frame_fsm.v
Fungsi: Pengawal tata bahasa protokol frame 192-bit (24 Byte) otonom di silikon.

  • Pencacah bit mandiri (0..191) kebal deadlock legacy.
  • Verifikasi seketika pada waktu sampel (Preamble 0xAAAA, Type 0xD391, Const 0x0DFFFFFE).
  • Meloloskan 72-bit payload dinamis secara transparan.
  • Menjebak pemotongan (<192b) dan kelebihan muatan (>192b).

🔒 Layer 3: Fail-Closed Isolation

Modul: ares_isolation_l3.v
Fungsi: Eksekutor pemutusan bus seketika dan isolasi data mutlak ke 8'h00.

  • Priority Arbiter (prioritas L1 > L2 tanpa latensi).
  • Sticky Fault Latch (mengunci bahaya dalam Tlatch = 1 siklus).
  • Zeroization Gate kombinatorial murni (Tisolate = 0 siklus / ~1.2 ns gate delay).
  • Interupsi hardware tamper_alert ke pin MCU.
Tiga Sifat Keunggulan Arsitektur: (1) Murni 0% Beban CPU Host (0 byte RAM, MCU tetap aman dalam mode tidur); (2) Anggaran Daya Ultra-Rendah (57.90 nW @ 20 kHz post-route estimate, >20 tahun CR2032); (3) Deterministik Mutlak (reaksi dalam 1 siklus tanpa ketergantungan OS).

Layer 1: Temporal Sentinel — Demarkasi Integritas Pulsa Fisik

Sanitasi Integritas Pulsa Baseband Real-Time & Penolakan Glitch Deterministik

⏱️ Spektrum Jendela Waktu

Transisi pulsa hanya diizinkan bila durasi siklus $N$ berada dalam jendela valid Manchester:

Siklus: 0 4 7 8 9 10 11 15 16 18 20 21 64+ Zona : [ RUNT GLITCH ][ HB ][ MIDBAND ][ BIT ][ GAP ][EOF] Vonis : [ ILEGAL: FLT ][LEGAL][ ILEGAL ][ LEGAL][ ILEGAL][OK] Durasi: 0 350 us 450us 600 us 900 us 1.05ms 3.2ms
  • Half-Bit (HB): $N \in [8, 10]$ ($400 - 500\,\mu\text{s}$, nominal $N=9$).
  • Full-Bit (BIT): $N \in [16, 20]$ ($800 - 1000\,\mu\text{s}$, nominal $N=18$).
  • Runt Fault: $N \le 7 \implies$ 3'b001.
  • Mid-Band Fault: $11 \le N \le 15 \implies$ 3'b010.

🔄 FSM Pelacak Konteks & Anti-Squelch

  • STATE_IDLE (2'b00): Menunggu edge pulsa masuk. reception_active = 0.
  • STATE_ARMED (2'b01): Menampung desis squelch awal (1..4 siklus). Jika timeout tanpa pulsa sah, kembali ke IDLE (Zero False Alarm).
  • STATE_ACTIVE (2'b10): Amplop aktif (reception_active = 1). Pelanggaran runt atau mid-band seketika memicu fault!
  • STATE_LONG_GAP_PENDING (2'b11): Jeda aktif $\ge 21$. Bila menyambung sebelum 64 $\implies$ fault 3'b011; bila hening hingga $\ge 64$ $\implies$ normal End-of-Packet reset.

🛡️ Tiga Prinsip Verifikasi Otonom

  • Pencacah Otonom (bit_counter [7:0]): Mencacah mandiri dari 0 hingga 191 pada saat serial_clock aktif. Sentinel tidak bergantung pada flag full demodulator legacy yang rentan hung/deadlock.
  • Sample-Time Verification: Setiap bit diverifikasi seketika pada saat sampel clock pertama tiba tanpa menunggu frame utuh dibaca ke RAM: $$\forall i \in [0, 95], \quad \text{Bit}_i == \text{Golden}_i$$
  • Transparansi Payload Dinamis: Bit 96..167 (telemetri ID sensor & suhu Peruri) diloloskan secara murni tanpa intervensi.

💥 Boundary Traps & Cuplikan RTL

  • Truncation Trap (AV07): Jika amplop jatuh sebelum 192 bit (<192b) $\implies$ fault 3'b111 (mencegah host memproses frame buntung).
  • Overrun Trap (AV08): Jika terdeteksi pulsa ke-193+ saat frame selesai (>192b) $\implies$ fault 3'b111 (mencegah heap buffer overflow).

Layer 3: Hardware Fail-Closed Isolation Subsystem

Isolasi Fisik Seketika, Gerbang Nol Mutlak, dan Sinyal Bahaya Non-Maskable

⚖️ Arbitrase Prioritas & Sticky Latch

Menyelesaikan anomali dalam siklus yang sama secara kombinatorial murni (latensi 0 siklus):

$$\text{Priority}: \quad L1\ \text{Temporal} \succ L2\ \text{Syntax}$$
  • Sticky Fault Latch: Mengunci bahaya pada clock edge berikutnya ($T_{\text{latch}} = 1\ \text{siklus} = 50.0\,\mu\text{s}$).
  • Non-Volatile Hardware State: Tidak dapat ditimpa oleh software atau derau lanjutan; hanya dapat dinolkan kembali melalui pin fisik rst_n.

🚫 Zeroization Gate Kombinatorial

Memaksa bus data paralel keluar menjadi 0x00 seketika dalam latensi gerbang silikon (~1.2 ns):

// Zeroization Gate RTL (ares_isolation_gate.v) assign out_data = (fault_latched) ? 8'h00 : in_data; assign out_valid = (fault_latched) ? 1'b0 : in_valid; assign tamper_alert = fault_latched; // Top-Level Wrapper (tt_um_ares_sentinel_project.v) assign safe_data_out = (tamper_alert_r) ? 8'h00 : raw_decoder_data; assign uo_out = safe_data_out & {8{halt}}; assign uio_out[6] = tamper_alert; // Pin Interrupt

⏱️ Jaminan Latensi Formal

  • Property 1 (Single-Cycle Latch):
    $$T_{\text{latch}} = 1\ \text{clock cycle} \ (50.0\,\mu\text{s} @ 20\,\text{kHz})$$
  • Property 2 (Zero-Cycle Bus Isolation):
    $$T_{\text{isolate}} = 0\ \text{clock cycles} \ (\approx 1.2\,\text{ns OpenSTA})$$
  • Property 3 (Deterministic Zeroization):
    $$\forall t \ge t_{\text{latched}}, \quad \text{uo\_out}[7:0] = 8\text{'h00}$$
Garansi Keamanan: Meniadakan 100% risiko korupsi data tersembunyi (silent corruption). Data berbahaya dimusnahkan sebelum menyentuh bus DMA atau memori host MCU.
